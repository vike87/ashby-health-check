# Security

Do not file issues containing candidate information, production exports or credentials. Reproduce problems with synthetic records. No backend, ATS writes or AI API integration is included. Deploy over HTTPS with access restricted to authorised staff for real data. Browser extensions, compromised endpoints and hosting access logs are outside the app’s guarantees. Do not claim forensic deletion or guaranteed anonymity.

Downloads may contain personal data. Apply access and retention controls. CSV formula-leading cells are prefixed with an apostrophe; spreadsheet behaviour varies, so review exports before opening them in privileged environments. Keep any future dependency changes minimal and pinned. Report vulnerabilities privately to the repository owner through GitHub private vulnerability reporting when available; otherwise contact the maintainer without including personal data.
